# 참바른약국 비서

- 휴대폰 웹앱: https://tobi06-oss.github.io/yakguk-biseo/ (이 저장소 맨 위의 index.html)
- PC 프로그램 자동 업데이트: `desk/` 폴더 (`desk/update.json`의 버전이 올라가면 약국 PC가 알아서 받아요)
- 클라우드: Firebase 프로젝트 `yakguk-biseo` (무매데스크와 별개)
- 이 저장소의 파일은 빌드 결과물입니다. 원본은 PC의 `약국비서_원본` 폴더에 있습니다.
- `vendor/firebase.js` 안의 설정값은 브라우저에 원래 공개되는 값이고, 자료 보호는 Firestore 보안 규칙이 맡습니다.
